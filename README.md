# ระบบสต็อกและจัดซื้อ

ระบบจัดการสต็อกและใบสั่งซื้อสำหรับร้านอาหารหลายสาขา คำนวณจำนวนสั่งรายสัปดาห์จากยอดใช้จริง ออกใบสั่งซื้อแยกตามผู้จัดจำหน่าย และนำเข้าสูตรกับรายชื่อผู้จัดจำหน่ายจาก FoodStory

ใช้ Node.js 24 ขึ้นไป ไม่มีไลบรารีภายนอก ข้อมูลเก็บในไฟล์ SQLite ไฟล์เดียว

## รันในเครื่อง

```bash
npm start
```

เปิด http://localhost:3210 ข้อมูลอยู่ในไฟล์ `stock.db` ข้างโค้ด ถ้าไม่ตั้ง `APP_PASSWORD` จะไม่มีหน้าล็อกอิน

## ติดตั้งบน Railway

1. สร้างโปรเจกต์ใหม่จาก GitHub repo นี้
2. ในบริการที่สร้าง ไปที่ Variables แล้วเพิ่ม `APP_PASSWORD` เป็นรหัสผ่านสำหรับเข้าระบบ
3. เพิ่ม Volume ให้บริการ ตั้ง mount path เป็น `/data` (ระบบจะเก็บฐานข้อมูลไว้ในนั้นเอง)
4. ไปที่ Settings > Networking กด Generate Domain เพื่อรับลิงก์เว็บ
5. เข้าระบบด้วยรหัสผ่าน แล้วย้ายข้อมูลจากเครื่องขึ้นไป: ในเครื่องเปิดแท็บ "ตั้งค่าเอกสาร" กด "ดาวน์โหลดไฟล์สำรอง" จากนั้นในระบบออนไลน์ใช้ "กู้คืนจากไฟล์สำรอง" ในแท็บเดียวกัน

ถ้าไม่ตั้ง `APP_PASSWORD` ระบบออนไลน์จะไม่เปิดให้ใช้ ถ้าไม่ต่อ Volume ระบบจะขึ้นแถบเตือนสีแดง เพราะข้อมูลจะหายเมื่อ deploy ใหม่

## ตัวแปรที่ตั้งได้

| ตัวแปร | ความหมาย |
|---|---|
| `APP_PASSWORD` | รหัสผ่านเข้าระบบ จำเป็นเมื่อรันออนไลน์ |
| `PORT` | พอร์ตของเซิร์ฟเวอร์ ค่าเริ่มต้น 3210 |
| `STOCK_DB` | ที่อยู่ไฟล์ฐานข้อมูล ถ้าต้องการกำหนดเอง |
| `TZ` | เขตเวลา ค่าเริ่มต้น `Asia/Bangkok` |
